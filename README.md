## 一页纸技术栈

```
客户端   Tauri 2 + React 18 + TypeScript + Ant Design 5 + Zustand
Agent    Rust sidecar（自研循环，stdio JSONL，OpenAI 兼容流式）
服务端   Go 模块化单体（gateway/auth/org/message/file/kb/
         app-registry/admin/audit/notify/ai-gateway）
数据     PostgreSQL 16（pgvector + zhparser + 按月分区）· Redis 7 · MinIO
AI       ai-gateway（模型无关）→ GLM / Qwen / DeepSeek / vLLM 私有化
交付     客户端内网自动更新（签名+灰度）；服务端 docker-compose / K8s
```

## 核心设计决策速览

1. **Tauri 2 而非 Electron**：系统 WebView，安装包 <30MB、空闲内存 <300MB（01 篇）。
2. **Agent 完全自研**：不用 LangChain 等框架；核心循环 + 工具协议自持，对齐 MCP 概念（08/09 篇）。
3. **Agent 一律以用户身份行事（OBO）**：降权短时效 token + act 声明 + 双写审计，禁止服务账号（03 篇 §6）。
4. **生态应用中心化分发**：管理员统一接入签名发布，用户端自动同步安装、更新、撤销（10 篇）。
5. **知识库权限过滤前置**：检索 SQL 注入用户可见集，绝不后过滤（11 篇）。
6. **多租户硬隔离**：tenant_id + PG RLS + 存储前缀（02/03 篇）。
7. **编码执行可插拔**：自研 Agent 是编排者，编码优先委派本地 Claude Code / zcode（headless 适配器），自研循环兜底；子智能体不持有任何公司凭证（17 篇）。
