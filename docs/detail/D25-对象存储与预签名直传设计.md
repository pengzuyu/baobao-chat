## 2. 对象布局（S3 模式）

```
bbc-data 桶（compose minio-init 已建，版本化）
  t/{tenant}/{sha前2}/{sha}            内容对象（13 篇 §6）
  t/{tenant}/{sha前2}/{sha}_t240.jpg   缩略 240
  t/{tenant}/{sha前2}/{sha}_t720.jpg   缩略 720
  s/{uploadID}                          分片会话对象（S3 multipart，uploadId 天然隔离；
                                        complete 后 copy 走、残留由 abort 兜底）
```

Local 模式布局不变（`files/{tenant}/{sha2}/{sha}`），缩略同目录 `_t240.jpg/_t720.jpg`。

## 3. 上传链路（init 响应新增 `mode` 字段，客户端跟随）

**relay 模式（Local，现状不动）**：`POST /files/upload`（≤20MB 中转）/ `init → PATCH /uploads/{id}/{no}（字节过服务端）→ complete`（本地 staging 合并）。

**presign 模式（S3）**：

| 步骤 | 内容 |
|------|------|
| init | 校验策略 → `CreateMultipartUpload(key=s/{uploadID})` → 响应 `{mode:"presign", part_size:8MB, part_total, parts:[{no,url,method:"PUT",expires_at}]}` 首批 ≤32 张（1h 时效） |
| 分片 PUT | 客户端并行 3 直传 MinIO（弱网失败降并行 1；PUT 403=签名过期 → status 续签该批，不计失败次数） |
| status | `GET /uploads/{id}?from_part=N` → ListParts 位图（断点续传）+ 续批预签名 |
| complete | `CompleteMultipartUpload(s/{id})` → 服务端 GET 流式 sha256 校验（不符 4006+Abort）→ CopyObject s→t（>5GB UploadPartCopy 环）→ 缩略图生成 → 建行（UK(tenant,sha) 兜底去重） |
| 秒传 | check/GetBySHA 不变；命中免上传 |

## 4. 下载票据

- S3 模式：`GET /files/ticket/{id}?variant=origin|240|720` → **预签名 GET（120s，对外端点+拼回 /oss 前缀）**，URL 为绝对地址；"一次性"语义=120s 短时效近似（S3 无法真一次性，07 §4.3 口径），审计记录随票据签发落。
- Local 模式：现状 token `/files/dl?t=` 相对路径不变。
- 客户端 `downloadUrl()`：`http` 开头直用，否则拼 apiOrigin。

## 5. 缩略图

- 生成时机：入库成功后同步生成（image/jpeg/png/gif 解码 + `image/jpeg` 编码 240/720 长边等比；宽高 ≤ 档位跳过该档）；失败不阻塞上传（thumbs 缺省=客户端回退原图）。
- 消费：消息流图片气泡 `s240`（点击查看原图 `origin`）；FileSendPreview 沿用原图。

## 6. 配置与部署

| 环境变量 | 说明 |
|----------|------|
| `BBC_S3_ENDPOINT` | 服务端→MinIO 内部端点（`http://minio:9000`）；**空=Local 回落** |
| `BBC_S3_PUBLIC_ENDPOINT` | 预签名对外基址（`https://域名/oss` 或 `http://内网IP:9000`）；含路径前缀则 URL 拼回 |
| `BBC_S3_ACCESS_KEY/SECRET_KEY` | compose .env.tpl 已有 |
| `BBC_S3_BUCKET` | 默认 bbc-data |

- nginx：`location /oss/ { proxy_pass http://minio:9000/; proxy_set_header Host $host; }`（trailing slash strip 前缀 + Host 透传=签名可验）。
- MinIO CORS：`mc cors set` 允许 app origins `PUT/OPTIONS`（webview fetch 直传预检；img src 下载无 CORS 约束）——并入 minio-init。
- 迁移：`deploy/compose/migrate-files-to-minio.sh`（mc mirror `data/files/{t}/ → bbc-data/t/{t}/`；file 表零改）；Local→S3 切换单向，切换后新增文件不再落本地盘。
