## 1. 概述与范围

### 1.1 范围与入口形态（12 篇 §1.1）

| 入口 | 形态 | 约束 |
|---|---|---|
| 客户端内嵌 | 主导航「⚙管理」（持有任一 admin:\*/platform:\* 可见，perm.changed 动态显隐） | 凭据跟随主会话（钥匙串） |
| Web 管理台 | `https://admin.<内网域名>`，同一 `features/admin/` 以浏览器目标构建（§8.3） | **refresh token 不落地**（仅内存）；闲置 15 min 锁定遮罩重验解锁 |

覆盖平台运营域（platform:\*，跨租户）与租户管理域（admin:\*）共 15 页；应用/技能 6 页（PEC-01~06）在 D09 定义、本篇提供 shell 与路由挂载。

### 1.2 设计原则落地（12 篇 §1.2）

权限驱动渲染（服务端唯一判定）；一切管理操作写 `admin_operation` 并入审计哈希链（15 篇）；导入 >100 行 / 导出 >1,000 条转异步任务（`admin_task` + WS 进度）；高危操作按 §4.1 矩阵走 A/B/C 档；/admin/\* 与 /platform/\* 前缀、权限点、审计策略硬分离。

### 1.3 权限点（12 篇 §6.3，本篇无新增）

admin:org:manage / admin:user:manage / admin:user:offboard / admin:role:manage / admin:role:assign / admin:app:publish（D09 用）/ admin:policy:manage / admin:kb:govern / admin:audit:read / admin:audit:export / admin:usage:read / admin:agent:revoke / platform:tenant:manage / platform:quota:manage / platform:monitor:read / platform:agent:killswitch。**缺口**：公告发布无专用权限点（§10-2 建议新增 admin:notice:publish）。

### 1.4 与其它模块篇的边界

D09（应用发布向导/灰度/技能）、D07（KB 空间内部交互）、D08（Agent 会话视图）、15 篇（哈希链/水印/KMS 机制）、16 篇（平台监控数据源）。本篇只定义管理交互、审批/任务流与聚合接口。

全局组件：`AdminShell`（模块树×权限交集）、`SecondAuthGate`（A/B 档）、`DangerConfirm`（D01 §8 三级：普通/危险红钮/高危确认词）、`ApprovalLauncher`（C 档）、`TaskProgressPanel`（右下角任务角标，WS 驱动）、`IdleLock`（Web 15 min 遮罩）。管理域无详情侧栏（D01 §5.3），宽内容区。

### 3.1 PAD-01 管理台登录与二次验证

```
┌─ Web 登录 ────────────────┐  ┌─ 二次验证弹窗（A 或 A+B 档）────────┐
│ Logo 租户名                │  │ 即将执行: 下架应用 com.company.oa    │
│ [工号/邮箱____________]    │  │ [口令________] [TOTP______](B档)    │
│ [口令________________]    │  │ [获取 5 分钟操作凭证]  剩余尝试 5    │
│ [TOTP________](若策略)    │  └─────────────────────────────────────┘
│ [登录]  SSO▸(若启用)      │  票据条: 🔓高危凭证 ●4:37 → 过期自动重验 │
│ 失败5次锁定10min(1005)     │  客户端内嵌: 无登录页, 复用主会话        │
└───────────────────────────┘  闲置15min→IdleLock→重验解锁(15篇§3.4)  │
```

| 区块 | 内容 | 数据/规则 |
|---|---|---|
| Web 登录表单 | 账号+口令+TOTP | auth 域登录（03 篇 §2.3）；token 仅内存 |
| 二次验证弹窗 | `SecondAuthGate` | POST /admin/second-auth → 票据 5 min 单用途，`X-Second-Auth` 头携带；过期/用途不符→9008 重弹 |
| 票据状态条 | 剩余时间倒计时 | <60 s 变黄提示「将过期」；每次矩阵操作前校验（INT-ADM-01：A/B 档获取→5min 倒计时→过期 9008 重验，票据单用途原子消费） |
| 闲置锁定 | 15 min 遮罩 | Web 强制；客户端管理页同策略（租户可配） |

### 4.2 双人审批流（INT-ADM-02，C 档）

```
发起人(操作页)          审批人(持目标权限点)           admin 服务            被影响方
```

### 4.3 异步任务模式（INT-ADM-07）

提交（导入/导出/交接/发布/对账）→ `admin_task(pending)` → 队列调度 `running`（progress 0–100 经 WS `admin.task.updated` 推送）→ `succeeded`（result.report_file_id）→ 通知中心+`TaskProgressPanel` 完成 toast → 报告下载（GET /tasks/{id}/report，预签名 15 min，**7 天过期**→expired 展示态、9007）。任务面板列本人全部任务（GET /admin/tasks）；服务重启幂等续跑（行级 checkpoint），不可恢复标 failed 可重试。同类型并发 1/操作人、租户并发导入 ≤3（表约束）。

### 4.4 批量选择器（INT-ADM-06，PAD-04/05/06/11）

选择集存 `store/batchSelection`（key=id 的 Set，**跨页保持**）；表头三态：选择本页 / 「全选筛选结果 N 条」横幅（服务端按当前过滤条件圈定 id 集，导出走异步）/ 清空；翻页/改筛选不清空选择但横幅提示「选择集含不在当前筛选内的 M 项」；批量操作执行前后选择集快照入审计 params。

### 4.5 组织拖拽与批量移动（INT-ADM-05）

拖拽：节点手柄 dragstart→合法目标高亮（自身/子孙节点不高亮）→ drop 时**环检测**（target.path 前缀含 dragged.id → 拒绝+toast「不能移动到自己的子部门」）→ 确认弹窗列子树影响（N 部门/M 用户/挂靠空间与部门群将随动，03 篇 §4.5 收敛）→ PATCH /depts/{id}{parent_id}（含排序 order）。批量移动=batch-move 接口逐节点校验（任一环→整批拒绝并回显行级原因）。拖拽预览层 z-index=800（D01 §6）。

### 4.6 审计导出与内容项（INT-ADM-09）

默认**仅元数据**导出（A 档）。含内容项（消息正文/文件名/检索片段）：①租户策略 compliance.audit_content_export=true（否则 8006 拒绝）→ ②C 档双人审批，**单次授权 24 h 有效**（审批通过后 24h 内可发起一次内容导出，窗口过后需重审）→ ③导出文件每行/页眉水印（导出人工号+姓名+时间+任务 ID）→ ④下载链接绑定操作人设备指纹、7 天过期；导出行为本身入审计。审计合规员默认仅元数据（12 篇 §7.2）。

### 4.7 killswitch 高危流（INT-ADM-10）

入口 PAD-14（platform:agent:killswitch）→ 影响预览（POST killswitch{dry_run:true}：活跃会话数/受影响租户数/当前速率）→ 二次验证 A 档 → 发起 C 档审批 → **输入确认词「暂停全部 Agent」** → engage：所有租户 agent 会话暂停（运行中工具调用按调用时刻放行完成）、工作台 degraded 横幅、通知全部在线管理员 → 状态条「⛔ 已暂停（可恢复）」→ 恢复=A 档（同样留痕）；全程双审计（平台域+各租户域标记，12 篇 §7.3）。

### 4.8 状态机

**admin_task**（12 篇 §5；expired 为派生展示态）

```
pending ─调度→ running ─→ succeeded ─报告保留7d→ (展示)expired
   │           │├─失败→ failed（可重试→pending）
   └─取消→ canceled      └─操作人取消(pending/running)→ canceled
```

| 当前 | 事件 | 下一 | 守卫/说明 |
|---|---|---|---|
| pending | 队列调度 | running | 同类型并发 1/操作人；租户导入 ≤3 |
| running | 进度 | running | progress 0–100，WS 推送 |
| running | 完成 | succeeded | result 记 report_file_id/expires_at=+7d |
| running | 异常 | failed | 幂等续跑失败的终态；可手动重试 |
| pending/running | 取消 | canceled | 仅操作人；执行中任务按 checkpoint 中止 |
| succeeded | expires_at 到期 | （展示）expired | **status 不变**，报告 9007；避免改写已审计记录 |

**admin_approval**（12 篇 §5）

| 当前 | 事件 | 下一 | 守卫 |
|---|---|---|---|
| pending | decide(approve) | approved | 审批人持权限点且≠发起人；高危 op 需两级时第一级通过仍 pending（记录 L1） |
| pending | decide(reject) | rejected | 拒绝备注必填；发起人收 9010 通知 |
| pending | 24h TTL | expired | 定时任务；通知发起人重新发起 |
| pending | 发起人撤回 | canceled | 本篇补充态（不改语义，见 §10-4） |

### 6.1 服务端 DDL（13 篇规范；平台域表无 tenant_id 业务过滤）

```sql

  id              bigint PRIMARY KEY,
  tenant_id       bigint NOT NULL,      -- 平台域操作记录平台租户视角
  operator_id     bigint NOT NULL,

  params          jsonb,                -- 变更 diff/审查清单勾选（脱敏后）
  result          text NOT NULL,        -- success|partial|failed
  second_auth     text NOT NULL DEFAULT 'none',  -- none|password|password+mfa（票据 ID）
  approval_id     bigint,               -- 关联 admin_approval（可空）

  created_at      timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_adm_op_time ON admin_operation(tenant_id, created_at DESC);
CREATE INDEX ix_adm_op_operator ON admin_operation(operator_id, created_at);
CREATE INDEX ix_adm_op_target ON admin_operation(action, target_id);

CREATE TABLE admin_task (               -- 异步任务
  id              bigint PRIMARY KEY,
  tenant_id       bigint NOT NULL,
  type            text NOT NULL,        -- user_import_preview/user_import_exec/audit_export/
                                        -- offboard/app_release/security_reconcile(15篇)
  status          text NOT NULL DEFAULT 'pending',  -- pending/running/succeeded/failed/canceled
  progress        smallint NOT NULL DEFAULT 0,      -- 0-100
  params          jsonb, result jsonb,              -- result 含 report_file_id/expires_at
  operator_id     bigint NOT NULL,
  created_at      timestamptz NOT NULL DEFAULT now(),
  started_at      timestamptz, finished_at timestamptz,
  expires_at      timestamptz          -- 报告保留 7 天（展示态 expired 判据）
);
CREATE INDEX ix_adm_task_op ON admin_task(tenant_id, operator_id, status);
-- 约束: 同一 operator 同 type pending/running 并发 ≤1（部分唯一索引）

CREATE TABLE admin_approval (           -- 双人审批工单
  id              bigint PRIMARY KEY,
  tenant_id       bigint NOT NULL,
  op_type         text NOT NULL,        -- app.publish/role.change/tenant.destroy/...
  target          text NOT NULL,
  requester_id    bigint NOT NULL,
  approver_id     bigint NOT NULL,      -- 服务端校验 approver ≠ requester
  level           smallint NOT NULL DEFAULT 1,   -- 两级审批时=2（二级审批人）
  status          text NOT NULL DEFAULT 'pending', -- pending/approved/rejected/expired/canceled
  reason          text, decision_note text,
  created_at      timestamptz NOT NULL DEFAULT now(),
  decided_at      timestamptz,
  expires_at      timestamptz NOT NULL DEFAULT now() + interval '24 hour'
);
CREATE INDEX ix_adm_appr_pending ON admin_approval(tenant_id, approver_id, status) WHERE status='pending';

CREATE TABLE admin_policy (             -- 租户策略（02 篇 §6 配置库表化）
  id              bigint PRIMARY KEY,
  tenant_id       bigint NOT NULL,
  domain          text NOT NULL,        -- security|compliance|kb|agent|im
  key             text NOT NULL,        -- 如 security.mfa / agent.audit_report_level
  value           jsonb NOT NULL,
  version         int NOT NULL DEFAULT 1,
  updated_by      bigint NOT NULL,
  updated_at      timestamptz NOT NULL DEFAULT now(),
  UNIQUE (tenant_id, domain, key)       -- 热点项冗余至 tenant.settings 快照
);

CREATE TABLE tenant_quota (             -- 平台域（无 RLS，仅 platform 服务读写）
  tenant_id       bigint PRIMARY KEY,
  plan_code       text NOT NULL,
  limits          jsonb NOT NULL,       -- seats/storage_bytes/ai_token_month/call_concurrent/kb_spaces
  usage           jsonb NOT NULL DEFAULT '{}',  -- 计量快照（派生可重算）
  version         int NOT NULL DEFAULT 1,        -- 乐观锁
  updated_by      bigint NOT NULL,
  updated_at      timestamptz NOT NULL DEFAULT now()
);
```
