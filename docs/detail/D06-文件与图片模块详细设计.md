## 1. 概述与范围

本文是 07 篇（文件与图片传输概要）的详细设计：传输管理器/查看器/发送预览/我的文件/群文件/外链访问六页面，上传下载任务状态机，REST 全参数（check → 预签名分片 → complete → download-ticket 全链），WS 事件 payload，DDL 级模型与客户端断点位图表，features/files 文件级划分。

| 项 | 范围 |
|---|---|
| 覆盖页面 | PFL-01 传输管理器 / PFL-02 图片查看器 / PFL-03 发送前预览 / PFL-04 我的文件 / PFL-05 群文件页签 / PFL-06 分享创建与外链访问页 |
| 覆盖能力 | 分片上传（4MB/片、并行 3、预签名按批 ≤32）、秒传、断点续传（位图）、坏块定点重传、下载票据、病毒扫描钩子、图片三档缩略与查看器、分享三要素、配额与清理建议 |
| 覆盖消费者 | im（image/file 消息卡片）、doc（06 篇引用）、kb（11 篇摄入）、avatar/app 系统对象（source 区分） |

**术语沿用 07 篇**：blob/file 两层模型、秒传（sha256 租户内去重）、分片（4MB）、预签名 URL、断点位图、staging、download-ticket、三要素（有效期/次数/密码）、三档缩略（webp 240/720/原图）、严格/宽松扫描模式。设计规范（令牌/六态/断点/反馈）按 D01。

## 3. 页面详细设计

### 3.1 PFL-01 传输管理器

```
┌ 传输管理器 ────────────────────────────────────────────────┐
│ [进行中 (2)] [已完成] [失败 (1)]     ⚙ 默认下载目录: ~/Downloads/BaobaoWork [改] │
│ ├─ 下载行为: (●)默认目录  ( )每次询问 ── 设置项（写入 files_prefs） ─┤
│ ┌────────────────────────────────────────────────────────┐ │
│ │ ↑ 季度汇报.pptx   128MB/256MB  18.2MB/s  剩余 ~8s       │ │
│ │ │ ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░ 50%   [位图: ██▓░██▓░░…]          │ │
│ │ │ 发送至: 产品研发群              [⏸暂停][✕取消]          │ │
│ │ ↓ 设计稿_final.zip 12MB/890MB  6.1MB/s  [⏸][✕]          │ │
│ │ ✕ 财务数据.xlsx  4002 类型被管理员禁止 [重试][✕移除] [详情▸bad_parts] │ │
│ └────────────────────────────────────────────────────────┘ │
│ 已完成 tab: [📄名 大小 时间 ⇱在文件夹显示] hover:[重新下载][移除]    │
└────────────────────────────────────────────────────────────┘
```

| 区块 | 说明 |
|---|---|
| 三 Tab | 进行中（上传+下载合并列表，badge 计数）/ 已完成（近 7 天，含"已秒传"标记）/ 失败（错误码文案+重试） |
| 传输项 | 方向图标 ↑↓ / 名称 / 已传/总量 / 实时速度 / 剩余时间估算 / 操作（⏸↔▶、✕、失败项重试） |
| 位图条 | 见 3.1.1 断点续传进度条 |
| 目录设置 | 默认下载目录展示+[改]（fs_pick_dir）；下载行为单选（默认目录/每次询问） |
| 失败详情 | 展开 bad_parts 列表（"第 12、13 片校验失败，将只重传这 2 片"） |

**六态表**：

| 态 | 触发 | 表现与允许操作 |
|---|---|---|
| loading | 引擎状态回灌 | 条目骨架×4（<300ms 防闪烁） |
| empty | 无任务 | 插画"暂无传输任务"+说明"拖入文件或粘贴截图即可发送" |
| error | 任务失败 | 条目红叉+错误码文案+[重试][移除]；trace_id 折叠 |
| offline | WSS 断 | 顶部横幅"连接中…，传输暂停将自动恢复"；进行中任务继续（直传不依赖 WSS），complete 暂缓 |
| forbidden | 4002/4012 等策略 | 条目态呈现对应文案；不可重试项隐藏重试 |
| degraded | MinIO 故障退避 | 条目黄条"存储服务暂不可用，自动重试中（第 n 次）" |

#### 3.1.1 断点续传进度条（PartBitmapBar）

| 项 | 规范 |
|---|---|
| 视觉 | 进度主条（0–100%，确定性）+ 下方位图网格：每格=1 片（4MB），已传=success、失败=danger、进行中=info 流动、未传=gray-3；>64 片自动抽稀（1 格=8 片） |
| 交互 | hover 格子 tooltip"第 N 片 · 4MB · 已传/失败"；失败格点击=单独重传该片 |
| 数据 | 引擎每片完成回推事件（transfer 事件，非 WS）；位图与本地 SQLite 镜像一致 |

```

│ ← 3/12 →   季度汇报截图.png  1920×1080  [对比] │
│ ┌──────────────────────────────────────────┐ │
```

| 区块 | 说明 |
|---|---|
| 顶栏 | 位置指示 n/N、文件名、原始分辨率、[对比]入口 |
| 画布 | 渐进加载：进入先显 720（预加载缓存），放大 >100% 或点"查看原图"加载原图（>5MB 提示"加载原图 约 8MB [加载][取消]"） |
| 工具条 | 缩放/旋转（90° 步进，状态不持久）/全屏；复制=写系统剪贴板（图片位图）；保存=默认目录；另存为=fs_save_as |
| 画廊条 | 会话内全部 image 消息集合（当前定位高亮）；←/→ 翻页切换（预取相邻 720） |

**六态**：loading=720 拉取（画布区 shimmer）；empty=不适用（必有来源图）；error=原图 4013/票据失效（4014 重取票据自动重试 1 次）；offline=查看已缓存缩略图，原图不可加载提示；forbidden=4015 严格模式扫描中（见 INT-FL-08）/分享失效（4010/4012 失效态页）；degraded=弱网降低缩略档位提示。

| 项 | 规范 |
|---|---|

| 区块 | 说明 |
|---|---|
| 筛选 | 类型（扩展名映射）/ 来源（1 chat 2 doc 3 kb 4 avatar 5 app）/ 时间（近 7/30 天/自定义）；排序（最新/最大，清理场景默认最大） |

六态：loading=骨架×8；empty="还没有文件，去会话里发送或从聊天中收藏"；error=重试+trace_id；offline=本地缓存（file_cache 24h）+遮罩；forbidden=2001（无 file:upload 时页面只读）提示；degraded=配额接口失败时水位条隐藏并提示"用量未知"。

#### 3.4.1 配额水位条（QuotaBar）

| 档 | 视觉 | 行为 |
|---|---|---|
| <80% | primary 常规 | 只读展示 |
| 80–89% | warning 色（浅） | 无打扰 |
| ≥90% | warning 色 + 呼吸动画 | 浮层预警（首次每次登录提示 1 次）："空间即将用满"[查看清理建议]；对应 WS file.quota.warning 触达 |
| 100%（4001） | danger | 上传预检直接拦截并弹清理建议 |

## 4. 交互详细设计

### 4.1 INT-FL 交互事件表

| ID | 交互 | 触发→行为→反馈 | 边界 |
|---|---|---|---|
| INT-FL-01 | 拖入投放 | 拖文件入主窗会话/文档区→投放高亮区（虚线框+"松开发送 N 个文件"）→松手进 PFL-03（图片）或文件确认条（非图片，直接入队+消息确认） | ≤20/次；超出 toast 分批提示（D01 §10）；拖出方向（卡片→系统）触发下载到拖放目标 |
| INT-FL-02 | 截图粘贴 | 输入框 paste 捕获 image → fs_capture_clipboard_image 写临时文件 → PFL-03 预览 → 发送 | 多图剪贴板逐张列出；粘贴文件路径文本不拦截 |
| INT-FL-03 | 秒传命中 | check 返回 dedup=true → 秒传提示条（绿色 toast"已秒传"，传输管理器已完成 tab 标"⚡秒传"）→ 直接发消息 | 命中不暴露首传者（07 §7.7） |
| INT-FL-04 | 暂停/恢复 | [⏸]→引擎停发未完成分片、位图落盘、条目灰态；[▶]→GET /uploads/{id} 对齐服务端位图后续传 | 恢复先对齐再传（双端状态一致）；暂停态不占服务端资源 |

| INT-FL-06 | 失败重试 | 失败条目 [重试]→4003 带 bad_parts 时仅重传坏片（续签该片 URL），否则整任务幂等重试（upload_id/指纹复用） | 连续 3 次 complete 失败→4008 会话作废→提示重新上传（本地未变可直接秒传重试） |
| INT-FL-07 | 下载触发 | 卡片 [⬇]：按设置"默认目录"直下或"每次询问"弹 fs_save_as；同名自动 ` (n)` 追加不覆盖 | 票据 120s 一次性，过期自动重取（4014 透明处理）；进入传输队列可见进度 |

### 4.2 上传任务状态机（客户端引擎权威态；右列映射 transfer_record.state）

```
pending → hashing → checking → uploading(paused/resuming 子态) → merging → done
                │                │      ▲                        │
                │                ▼      └── bad_parts 定点重传 ───┤
                │             failed ──────重试(幂等)→ uploading ──┤
                └─ 预检失败 → failed                                     ▼
   任一非 done 态 ←─ 用户取消 → canceled（清理半成品）             done
```

| 状态 | 进入 | 允许操作 | 映射（服务端 state） |
|---|---|---|---|
| pending | 入队 | 取消 | queued |
| hashing | 本地预检通过，计算 sha256（分块并行，进度回传） | 暂停（中止计算，恢复重算缓存块）/取消 | queued |
| checking | POST /files/check | 取消 | queued |
| uploading | 未命中，PUT 分片并行 3 | 暂停/恢复/取消；弱网自动降并行 1 | transferring / paused |
| paused | 用户暂停（位图落盘） | 恢复/取消 | paused |
| resuming | 恢复中（GET 位图对齐+续签 URL，≤3s） | 取消 | transferring |
| merging | 全片 PUT 完，POST complete（校验/合并/终验） | 不可取消（按钮禁用） | processing |
| done | 返回 file_id（或 check 秒传直接进入） | —（入已完成 tab） | done |
| failed | 4001/4002/4003/4004/4006/4007/4008/4009… | 重试（4003 坏片定点）/移除 | failed |
| canceled | 用户取消 | 重新入队（指纹复用） | canceled |

超时与重试：单片 PUT 失败指数退避 ≤3 次；请求 10s 无 ack 超时重试（14 篇 §2.2）；complete 幂等键 upload_id。expired：服务端 4008 或 WS file.transfer.expired → failed（会话过期文案，保留本地文件供重新上传）。

### 4.3 下载任务状态机

```
pending → ticketing(取票据) → downloading(paused/resuming) → writing(拼接校验) → done
                                   │                            │
                                   ▼                            ▼
                 scanning(打开前钩子，严格模式 4015) ──────► opened
   失败(4001x/4005/4013/4014) → failed ──重试──► pending；取消 → canceled（清理 .part 半成品）
```

| 状态 | 说明 |
|---|---|
| ticketing | GET download-ticket（120s 一次性预签名 GET）；4014 自动重取 ≤2 次 |
| downloading | Range 断点续拉，并行 3 段；暂停/恢复/取消同上传 |
| writing | 分段拼接 + 落盘校验（Content-Length 与 sha256 可选校验）；同名 ` (n)` |
| scanning | 仅"打开"路径触发（INT-FL-08）；下载完成≠扫描完成 |
| done | 通知中心/transport 完成态；可选 toast"下载完成 [打开][所在文件夹]" |

### 5.2 预签名 PUT 语义（引擎实现约束）

| 项 | 约定 |
|---|---|
| 方法/对象 | PUT 单对象单操作（一 URL 一片），不暴露 AK/SK；签名含 Content-Length 范围 |
| 头 | `Content-Type: application/octet-stream`；`Content-Length` 固定 4MB（末片=余量）；不带 Authorization（签名在 URL query） |
| 分片大小 | 4MB 固定（part_total=ceil(size/4MB)；10GB=2560 片）；分片号 5 位定长命名 `{part_no:05d}` |
| 批量 | 预签名按批 ≤32 URL/批，时效 1h；到期前 10min 引擎主动续签（API-FL-03）；失败重签同接口 |
| 并行 | 并行 3；弱网（速度 <50KB/s 持续 30s）自动降 1 并 toast"网络较慢" |
| 校验 | 每片响应 etag 记录（complete 凭证）；PUT 200 ≠ 内容正确，终验在 complete（07 §7.2） |
| 下载对称 | GET 预签名 120s 一次性；Range: bytes=offset- 续拉；并行 3 段 |

## 9. 边界与异常

| 场景 | 处理 |
|---|---|
| 上传中策略变更 | 已建会话按创建时策略跑完；新会话按新策略（07 §7.7） |
| MinIO 故障 | 引擎指数退避自动重试（transferring 保持），IM 文本消息不受影响（02 篇 §7） |
| 客户端崩溃/退出 | transfer_task+bitmap 落盘；重启 GET /uploads/{id} 双端对齐后续传 |
| 同名文件 | 云端多实例并列（name 非唯一键）；下载 ` (n)`；群文件按上传者区分 |
| 撤回文件消息 | 仅卡片失效；file 保留在发送者"我的文件"（07 §7.7，联动 D03 msg.recall） |
| 回收站/清理 | 软删 30 天→物理删（ref_count−1）→孤儿 blob >7 天 GC；全程审计+运维二次确认（07 §7.4） |
| 阳性文件（4004） | 下载/预览/分享全链路拦截；隔离+通知 owner 与管理员；仅 file:manage_all 可处置 |
| 秒传隐私 | 命中仅返回 dedup=true，不暴露首传者；跨租户 UK 保证绝不去重 |
| 弱网 | 并行降 1；<50KB/s 持续 30s 提示"网络较慢，可稍后继续"；暂停态零服务端占用 |
| 预签名到期 | 到期前 10min 自动续签；PUT 403 视为过期→重签该批（不计入失败次数） |
| 大图内存 | 查看器原图按需解码+canvas 平移；>50MP 图片提示降档查看 |
