## 1. 概述与范围

本文档是 11 篇（知识库系统）的详细设计，覆盖**三级空间模型、五种内容来源入口、摄入进度可视化、混合检索面板、空间授权与敏感治理**的页面/交互/接口/模型/模块结构。术语、权限点（kb:*）、错误码（7xxx）、WS 事件（kb.updated）、表名（kb_*）一律沿用 11 篇与 14 篇；超出概要篇的内容在 §10 登记并标注"待回填"。

### 1.1 范围内 / 范围外

- **内**：PKB-01..09 九页面与六态；三空间切换可见性差异、目录拖拽移动、上传校验（7006/7007）、五种入库来源入口、摄入失败重试续跑、检索交互（防抖建议/结果展开/引用复制）、授权（user/dept+治理角色+打破继承）、敏感标记二次确认、个人空间不可删（7010）；摄入任务状态机；REST 全参数（含 kb_query 全字段与 OBO 语义）+ WS kb.updated payload；kb_* 七表 DDL（HNSW/GIN）+客户端 SQLite+TS；features/kb/ 目录树与 agent/doc/im bus 交互点。
- **外**（归他篇）：摄入 worker/LibreOffice/bge 模型部署（16 篇）；ai-gateway 计量（D10）；抓取连接器管理界面（阶段四，仅预留 source_type=crawl 入口）；Agent 侧 kb_query 工具注册细节（09 篇/D08）。

### 1.2 本篇关键设计决策（矛盾点详见 §10）

| # | 决策 | 说明 |
|---|---|---|
| K1 | 检索建议（防抖下拉）**不新增服务端接口**，用本地检索历史+可见空间名做前缀建议 | 概要篇未定义建议接口；服务端 suggest 留作二期（OP-2） |
| K2 | 摄入进度"轮询 GET /kb/jobs/{id}（2s 起、指数退避至 10s 封顶）+ WS kb.updated(doc.ready/doc.failed) 双通道"，WS 到达即停轮询 | 11 §6.2 注明进度走轮询；本篇叠加 WS 提速，事件 kind 不变 |

| 区块 | 内容 | 数据绑定 |
|---|---|---|
| B1 检索框 | 回车→PKB-04；输入 300ms 防抖→本地建议（历史+空间名，K1） | local_kb_search_history + 空间列表 |

可见性差异（三空间切换语义）：个人 tab 仅本人空间（他人空间出现在此=曾被显式授权 user 粒度）；部门 tab=用户所属部门（含多部门）空间；公司 tab=全员可见空间（reader 起步）。无权空间任何 tab 均不可见（不做灰化占位，防空间名泄露）。

六态（B3）：loading=空间卡骨架×3；empty（如部门未建空间）="暂无部门空间，联系部门管理员创建"；error=码文案+重试；offline=缓存空间列表+遮罩（检索/摄入不可用）；forbidden=7002 全量无权→锁页（仅个人空间可用）；degraded=ai-gateway 不可用→黄条"检索降级为关键词模式"（11 §7.2）。

### 4.2 摄入任务状态机（11 §4.2 展开）

```
              ┌─────────── parsing ───────────┐
 pending ────►│ LibreOffice 解析+清洗          │─┐
 (队列)       └──────┬────────────────────────┘ │失败(120s 超时/损坏)
                     ▼                          │
              ┌─────────── chunking ──────────┐│
              │ 结构感知分块(512/重叠64/表格整块)│◄┘ 自动重试(退避, attempt≤3)
              └──────┬────────────────────────┘
                     ▼                          ┌─ failed(stage,error,attempt)
              ┌─────────── embedding ─────────┐│   ├ attempt<3: 自动重试(从 stage 续跑)
              │ bge-m3 批量嵌入(ai-gateway)     │├──►├ attempt=3: 停自动, 人工 reingest(7012)
              └──────┬────────────────────────┘│   └ 7008(嵌入服务不可用): 挂起排队不丢
                     ▼                          │
              ┌─────────── ready ──────────────┐│  purging(删除/更新替换): 物理清除旧索引
              │ kb_chunk 双索引提交(HNSW+GIN)   │◄┘  完成后 node.status 更新
              └───────────────────────────────┘
```

| 状态 | 客户端表现（IngestBadge） | 停留参考 |
|---|---|---|
| pending | 灰"排队中"（队列位次） | 积压时可见 |
| parsing | 蓝"解析中" | 秒级–2min |
| chunking | 蓝"分块中" | 秒级 |
| embedding | 蓝"嵌入中"（批量进度） | 随 ai-gateway 负载 |
| ready | 绿"就绪 v{n}"（可检索） | 终态 |
| failed | 红"失败@{stage}(第{attempt}次)" | 可重试 |
| purging | 灰"清除中" | 终态（节点删除） |

自动重试策略：阶段内异常退避重试（1m/5m/15m），attempt≤3；嵌入阶段遇 7008 挂起（不计数），服务恢复自动续跑。更新替换：sha256 变化→新一轮管线→**同事务**替换索引（先删旧插新）→version+1，检索无中间态（11 §4.2）。

```json
  "trace_id": "tr-7c1d" } }
```

**OBO 语义（K5）**：Agent 经 Runtime 以 `Authorization: Bearer <OBO JWT>`（含 `act:{agent_session}`）调用本接口；服务端以 `sub`（用户）执行：① 权限点 kb:query:use；② 生成可见 node/doc 集合（部门树展开+显式授权+空间可见性）注入 A/B 两路检索 WHERE（**权限前置过滤，绝不做检索后过滤**，11 §4.3）；③ top50 重排前实时 ACL 复核；④ kb_query_log 落 `user_id=sub, actor=agent:{session}`。Agent 通道限流更严（14 篇 §5.1）。人不传 act → actor=null。include_sensitive 无论来源均按 sub 实权判定，Agent 不可越权。

### 5.3 其余关键接口字段

**API-KB-07 上传入库**：`{file_id(必填，D06 上传所得), node_id?, name?}` → `{doc_id, node_id, job_id, status:"pending"}`。错误：7007（白名单外）、7006（>2000 页/解析产物>32MB，提示拆分）、7004（配额预检 11 §4.5）、7001。

**API-KB-09 文档中心同步**：`{doc_file_id, space_id, node_id?, sync_policy:"manual"|"auto"}` → `{doc_id, job_id}`；source_ref=doc_file_id；auto=doc.updated(version) 自动触发重摄入。

**API-KB-10 Agent 产出**：`{agent_session_id, content_type:"markdown"|"docx", title, space_id, node_id?, confirmed:true(前端确认标记)}` → `{doc_id, doc_file_id?(docx 时), job_id}`；OBO 调用时服务端复核 confirmed 并双审计。

**API-KB-08 IM 收藏**：`{msg_id? , file_id?(二选一), space_id, node_id?}` → `{doc_id, job_id}`；文本→md 笔记（source_ref=msg_id），文件→引用入库。

**API-KB-11 节点 PATCH**：`{name? , parent_id?(移动), sensitive?, sensitive_reason?, archived?, inherit_acl?}` → `{node}`；sensitive/inherit_acl 变更触发 acl_tags 刷新任务与审计。错误：7014（同名）、7005、7011（继承非法）、9001（拖入自身子树）。

**API-KB-13 重摄入**：`{from_stage?:"parsing"|"chunking"|"embedding"(缺省=parsing 全量)}` → `{job_id, attempt:1}`；重置 attempt 计数。错误：7012（人工前已达上限且未显式 reingest 语义区分）、7005。

**API-KB-14/15 任务**：`GET /kb/jobs/{id}` → `{job_id, doc_id, node_id, stage, attempt, last_error?, error_code?, stage_progress?(embedding 0-100), updated_at}`；列表同构+cursor。

**API-KB-16 详情**：→ `{doc_id, node, space, source_type, source_ref, source_url?(跳文档中心/IM), version, status, page_count, sensitive, outline:[{heading_path,seq}], preview_url?, updated_at}`。

**API-KB-19 授权**：`{grants:[{grant_type:"user"|"dept", grant_target, role:"owner"|"admin"|"contributor"|"reader", expires_at?}]}` → `{granted, skipped:[{target, reason}]}`；同事务写 resource_acl+kb_acl 投影（含 role 列）。错误 7011（移除唯一 owner 前置校验）、9001。

**API-KB-23 审计**：`GET ?from=&to=&kind=query|ingest|grant&sensitive_only=` → 分页事件列表（复用 12 篇审计展示组件）。

### 5.4 WS 事件 payload（登记于 14 篇 §3，字段以本篇为准）

kb.updated（S→C）：`space_id`(string) · `node_id?`(string) · `doc_id?`(string) · `job_id?`(string) · `kind`(doc.ready\|doc.failed\|perm.changed\|quota.warning\|space.updated) · `error_code?`(int，仅 doc.failed) · `used_bytes?`(int，仅 quota.warning) · `quota_bytes?`(int) · `by?`(uid)。

```json
{ "v": 1, "id": "s-88901", "type": "kb.updated", "ts": 1762420800123,
  "payload": { "space_id": "3001", "node_id": "41023", "doc_id": "51001",
    "job_id": "66001", "kind": "doc.ready" } }
```

客户端处理：doc.ready/doc.failed→摄入中心刷新（K2）+节点徽标更新+停轮询；perm.changed→Query 失效（['kb','nodes',spaceId]/['kb','spaces']）与检索结果缓存清空（收紧即时）；quota.warning→配额条变橙/红；space.updated→空间卡信息刷新。摄入进度本身走轮询（11 §6.2 注），WS 仅作完成信号。

`kb_clipboard_cite`（复制引用文本+深链入系统剪贴板）；`kb_open_source_external`（跳转源文件本地下载目录，配合 fs 层）。

## 9. 边界与异常

| # | 场景 | 处理 |
|---|---|---|
| 1 | 上传中删除目标目录 | 任务入队前校验节点存在；上传完成建 doc 时 7005→toast+文件保留在我的文件（D06） |
| 2 | 同一文档重复入库（同 node 同 source_ref） | 服务端幂等：返回既有 doc_id 并触发 sha256 比对（相同→no-op；不同→重摄入） |
| 3 | 检索期间权限收紧 | 已渲染结果不撤回（本地已见），新分页/新查询按新 ACL；pkb 文档直连 7009/7002 兜底（11 §4.3-3 复核） |
| 4 | 权限放宽滞后 | 新授权用户 ≤5min 内可检索（acl_tags 异步刷新）；期间提示文案见 11 §4.4，客户端不做本地补偿 |
| 5 | 摄入中源被删除（doc_file 入回收站） | doc_sync 来源：任务标记 failed(last_error=source_deleted)；KB 引用保留待源恢复或人工清除 |
| 6 | 大结果集分页 | top_k≤20/请求，cursor 翻页；"加载更多"累计 ≤100 提示收敛筛选 |
| 7 | 空间被归档（7013） | 浏览只读+📦标识；检索默认排除（空间设置可改）；治理者可恢复 |
| 8 | 个人空间主人离职 | 空间冻结 30 天只读（11 §7.8），客户端展示"冻结"横幅；移交/清除走 D10 流程 |
| 9 | 嵌入服务长时间不可用 | 任务停留 failed-pending（7008 挂起态徽标），不丢；恢复后续跑；检索自动降级（degraded 标记驱动黄条） |
| 10 | IM 收藏入库后原消息撤回 | KB 侧笔记/文件引用不受影响（入库即独立副本/引用）；引用回跳 IM 提示"原消息已撤回" |
| 11 | Agent 循环调用 kb_query | Agent 通道限流（14 篇 §5.1）9003→Runtime 侧退避（D08/D11） |
| 12 | 删除目录时子树含他人文档 | 级联确认列子树计数；权限不足的子文档跳过并在结果 toast 汇总"N 项无权删除" |
