## 模板（D01 §13）

概述与范围 → 页面与路由 → 页面详细设计（线框+六态） → 交互详细设计（INT 事件表+状态机） → 接口详细设计（全参数+示例 JSON） → 模型设计（DDL+TS 类型） → 响应式适配（四档断点） → 模块划分（目录树） → 边界与异常 → 开放问题。
