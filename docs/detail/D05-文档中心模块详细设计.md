## 1. 概述与范围

本文档是 06 篇（在线文档协作）的详细设计，覆盖客户端文档中心的**页面、交互、接口契约、数据模型与前端模块结构**。术语、权限点（doc:*）、错误码（6xxx）、WS 事件（doc.*）、表名（doc_*）一律沿用 06 篇与 14 篇，不引入新概念；确需超出概要篇的内容在 §10 开放问题登记并标注"待回填"。

### 1.1 范围内 / 范围外

- **内**：文档中心首页/列表/编辑壳层/只读预览/回收站全量页面与六态；新建（空白+模板）、分享、版本对比恢复、权限管理与申请审批、聊天文件转协作文档交互流；WOPI 会话客户端生命周期（状态机/心跳/断线重连/过期重开）；doc 域 REST 全参数+WOPI 主机端点+WS payload；doc_* 八表 DDL、客户端 SQLite、TS；features/doc/ 目录树与 bus 交互点。
- **外**（归他篇）：OnlyOffice DS 内部协同与部署容量（16 篇）；LibreOffice worker 池（16 篇）；文件域上传下载管线（D06，本文只消费 file_id 与下载票据）；KB 同步入库界面（D07）；租户策略配置界面（D10）。

### 1.2 本篇关键设计决策（矛盾点详见 §10）

| # | 决策 | 说明 |
|---|---|---|
| K1 | 引入 `doc_folder` 表（**超出 06 篇 §5，待回填**） | 概要篇左侧树是权限视图扁平模型；详细设计为支撑"移动/继承链可视化"冻结为：scope 根（我的/部门/公司）+ 用户自建文件夹两级结构。与 06 §9.3 矛盾 → 开放问题 OP-1 |
| K2 | 列表与 IM 卡片共用的文档卡片壳放 `shared/components/DocCard.tsx`（哑组件） | 遵守 D01 §12.2 禁止 feature 横向 import；数据 hooks 由 doc feature 提供，点击经 bus 广播 |
| K3 | 协作头像/presence 以 WS `doc.presence` 驱动，30s 无 leave 事件本地超时兜底清理 | 防连接抖动产生僵尸头像 |
| K4 | 心跳由渲染进程 `useHeartbeat` 驱动（5min），iframe 存活探测=visibility+postMessage ping | 会话续期双通道之一（06 §4.3） |

## 3. 页面详细设计

### 3.1 PDOC-01 文档中心首页

```
┌─主导航─┬─二级列表栏(264px·可折叠56)─────┬─内容区(PDOC-02 列表)──────────────┐
│📄 ●   │ [🔍 搜索文档________] [+新建▾] │ （见 3.2）                        │
│      ├───────────────────────────────┤                                   │
│      │ ▸🕐 最近打开(8)                │                                   │
│      │ ▸📁 我的文档                   │                                   │
│      │ ▸👥 与我共享                   │                                   │
│      │ ▸🏢 部门文档 ▾  ▸🏛 公司文档 ▾ │                                   │
│      │ ────────────  🗑 回收站(3)      │                                   │
└──────┴────────────────────────────────┴───────────────────────────────────┘
```

| 区块 | 内容 | 数据绑定 |
|---|---|---|
| B1 搜索框 | 域内搜索（名称模糊） | `GET /doc/files?q=`（防抖 400ms） |
| B2 新建按钮 | 下拉：Word/Excel/PPT/从模板新建/导入（聊天文件） | 打开 PDOC-04 / PDOC-11 |
| B3 左树 | 最近打开（本地 SQLite ≤20）+ 四个 scope 节点；部门/公司下挂 doc_folder 子树（懒加载，K1） | 最近=local_doc_recent；树=`GET /doc/files?scope=tree` |
| B4 回收站入口 | 角标=条目数 | `GET /doc/trash` 计数（缓存 5min，doc.updated kind=meta 失效） |

左树语义：scope 节点是**权限视图**（我的=owner 是我；与我共享=ACL 授予我且非 owner；部门/公司=grant_type=dept/tenant 聚合）；文件夹是物理归属（K1）。多部门展开按主部门优先排序。

六态（B3 树）：loading=树骨架（3 级条形）；empty="暂无文档"+CTA[新建]；error=码文案+重试；offline=本地缓存树+半透明遮罩"离线，仅浏览"；forbidden=2003 对应 scope 节点灰化+锁图标（不整页锁死）；degraded=doc-svc 降级黄条"文档服务暂不可用"（02 篇 §7）。

### 3.8 PDOC-08 只读预览

```
┌ 📄 接口说明.md（只读预览） [下载原文件] [⋯] ── 水印层(同 3.3) ─────┐
│ 转换中: ⏳ 正在转换为 PDF… 排队第 2 位（预计 40s） [改为下载原文件]  │
│ 就绪  : <PDF 渐进渲染（分页/缩放/文中查找）>  第 3/12 页           │
│ 失败  : ❌ 转换失败(6003) 已提供原文件下载  [重试转换] [下载]        │
└─────────────────────────────────────────────────────────────────────┘
```

| 区块 | 数据绑定 |
|---|---|
| 转换状态 | `POST /doc/files/{id}/preview` → {status: ready\|converting, url?, queue_position?}；converting 轮询 3s + doc.updated(kind=preview_ready) 双通道 |
| PDF 渲染 | PDF.js 分块 Range 懒加载页；禁止下载时禁右键/另存/拖出（水印+download=false） |
| 失败降级 | 6003 → 降级按钮=版本下载票据（06 §7.5；受下载权约束） |

六态：loading=转换中进度（queue_position→worker 进度）；error=6003 降级卡；offline="预览需在线查看，可下载后本地打开"（已缓存页可浏览）；forbidden=2003 申请入口；degraded=OnlyOffice 故障进入本页时黄条"编辑暂不可用"。

### 3.10 PDOC-10 权限申请与审批

申请弹窗（无权限接收方点"🔒 申请权限"或 forbidden 态 CTA）：文档名+所有者、申请档位（可查看/可评论/可编辑单选）、理由输入、[提交申请]；绑定 `POST /doc/files/{id}/permissions/request`。审批入口：owner 收 `doc.access.requested` → 通知中心卡片（申请人/文档/档位/理由+[同意][拒绝]），同意可调整档位；`POST /doc/permissions/requests/{rid}/approve|reject`；双方收 doc.updated(kind=perm) 后申请方卡片自动解锁。重复申请防抖：pending 中再提交→9001"已有待处理申请"。六态：loading=提交 spinner；error=toast；其余不适用。

```
              ┌────────── opening ────────────┐
  idle ─click►│ POST session(鉴权/建 token)   │─6001/2003─► forbidden(申请权限)
              └──────┬───────────────────────┘─6005/6007─► error(码文案)
                     ▼ ok(mode=edit)           ▼ ok(mode=view)
                 editing ◄────────────────► viewing(只读壳，无编辑心跳)
     心跳5min ✓ / WOPI流量 ✓ │
   iframe 连接错误/401       ▼        ┌──────────────────────────────┐
                          ┌─────────►│ reconnecting(黄条·缓存倒计时) │
                          │          │ 成功→restored→editing(2s)     │
                          │          │ 缓存超10min→lost(红·手动复制)  │
                          │          │ WOPI 401(6012)→expired        │
                          │          └──────┬───────────────────────┘
                          │                 ▼ expired
                          │        reopening(静默 POST session)─成功─►editing
       editing/viewing ──close/登出/吊销──► closed(终版快照, kind=closed)
```

| 状态 | 壳层职责 | 转移 |
|---|---|---|
| idle | 无 | — |
| opening | iframe 骨架+壳层按钮禁用 | REST 10s 超时→重试 1 次→error |
| editing | 启动心跳（5min）；监听 DS 连接事件 | 心跳失败 2 次→reconnecting |
| reconnecting | 黄条+10min 缓存倒计时 | 恢复→restored；超时→lost；401→expired |
| restored | 绿条 2s | →editing |
| expired | 红条 | 用户点击/自动→reopening |
| reopening | 保留滚动位置重挂 iframe | 失败→error+返回列表 |
| closed | 清理 store/心跳 | — |

### 5.2 关键接口字段表与示例

**API-DOC-08 打开会话**（最核心）。请求 `POST /doc/files/{id}/session`：`intent`(string，必填，auto/edit/view)；`did`(可选，缺省取 token)。

响应 data：

| 字段 | 类型 | 说明 |
|---|---|---|
| session_id / access_token | string | 会话 ID / JWT（exp≤10min，payload: sid,sub,file,mode,did,fam） |
| action_url / wopi_src | string | OnlyOffice 编辑器页 URL（iframe src）/ doc-svc WOPI 端点（注入 document.url） |
| mode | string | edit/comment/view（服务端折叠结果） |
| file | object | {id,name,doc_type,version_no,size} |
| presence | array | [{uid,mode}] |
| watermark / capabilities | bool / object | 壳层水印开关 / {download,print,copy}（收窄后） |

```json
{ "code": 0, "data": { "session_id": "71001",
  "action_url": "https://oo.example.com/web-apps/apps/editor/documents/index.js?...",
  "wopi_src": "https://api.example.com/wopi/files/90001", "access_token": "eyJhbGciOiJFUzI1NiIs...",
  "mode": "edit", "file": { "id": "90001", "name": "季度汇报.docx", "doc_type": "word", "version_no": 14, "size": 2201000 },
  "presence": [{ "uid": "2003", "mode": "edit" }], "watermark": true,
  "capabilities": { "download": true, "print": true, "copy": true } }, "trace_id": "tr-1a2b" }
```

错误：2003/6001（perm 不足 view）、6005（不存在/回收站）、6007（超大小→客户端预判拦截）、6014（管理员锁定→仅 view）、6002（会话满）。

**API-DOC-12 创建分享**。请求 `{perm:"view"|"comment", expire_mode:"1h"|"1d"|"7d"|"30d"|"forever", password?:string, allow_download:bool}` → 响应 `{share_id, url:"https://host/s/9f3a…c2", expires_at|null}`。错误 2003/9001/6005。

**API-DOC-16 批量授予**。请求 `{grants:[{grant_type:"user|dept|role|tenant", grant_target, perm:"viewer|commenter|editor|owner", expires_at?}]}` → `{granted:3, skipped:[{grant_target, reason:"already_higher_perm"}]}`；同事务写 resource_acl+doc_permission 投影并失效 ACL 缓存。错误 2003/9001。

**API-DOC-23 版本对比**。请求 `{base_vid, target_vid}` → A `{mode:"diff", action_url, access_token}`；B 降级 `{mode:"pdf_side_by_side", base_pdf_url, target_pdf_url}`。错误 6013/perm<viewer。

**API-DOC-02 聊天文件导入**。请求 `{file_id, conv_id(回发卡片目标会话), name?, folder_id?}` → `{doc_file_id, editable, version_no:1, card_msg_id(服务端回发 doc_card 消息 id)}`。错误 4005/6007(>100MB 建 editable 失败→自动建只读型 editable=false)/4015(扫描中)。

**API-DOC-03 列表**。`GET /doc/files?scope=recent|mine|shared|dept|company&folder_id=&q=&doc_type=&order=-updated_at&cursor=&limit=50` → `{items:[DocFileSummary], next_cursor, has_more}`。

**API-DOC-09/10 心跳与关闭**。heartbeat `{session_id}` → `{deadline, mode}`（mode 变化提示客户端升降级）；close `{session_id}` → `{final_snapshot:bool}`。

**API-DOC-11 预览**。请求 `{page?}` → `{status:"ready",url,version_no}` | `{status:"converting",queue_position,eta_sec}` | `{status:"failed",error:6003}`。

**API-DOC-28 恢复**。`{note?}` → `{file_id, new_version_no:15, renamed:true, name:"季度汇报 (恢复).docx"}`。

### 5.3 WOPI 主机端点（doc-svc 对 DS 暴露，非 /api/v1）

**token 校验语义（四端点一致，逐请求执行，绝不因会话已建立而跳过，06 §4.1 要点 3）**：① 验签（ES256）+exp；② doc_session=active 且 token_family deadline 未过（过→401，DS 报连接错误→客户端 INT-DOC-14）；③ 以 token.sub 身份重跑 03 篇三层判定（RBAC→数据范围→resource_acl）折叠能力集；④ 会话 revoked/关闭/force.logout→401。

| 端点 | 行为 | 关键返回 |
|---|---|---|
| W-01 GET /wopi/files/{id}（CheckFileInfo） | 元数据+能力 | BaseFileName/Size/Version(=version_no)/OwnerId/UserId/UserFriendlyName/UserCanWrite(perm≥editor)/SupportsUpdate=true/UserCanReview(≥commenter)/DisablePrint/DisableCopy(策略)/download=false(禁止下载)/Watermark 标志/PostMessageOrigin |
| W-02 GET /wopi/files/{id}/contents（GetFile） | perm≥viewer→MinIO 流式回工作副本；X-WOPI-Version≠current_version→409 触发 DS 重拉 | 200 字节流，Content-Disposition inline |
| W-03 POST /wopi/files/{id}/contents（PutFile，X-WOPI-Override:PUT） | perm≥editor（否则 403→编辑器转只读）；校验 base_version/sha256 基线，不符→6004 落分叉副本；写穿 working_key；节流快照 5min | 200 `{version_no}` |
| W-04 POST /wopi/files/{id}/action | action=close/forced_save→终版快照/强制保存点；发 doc.updated | 200 |

### 5.4 WS 事件 payload（登记于 14 篇 §3，字段以本篇为准）

| type | payload 字段 |
|---|---|
| doc.updated | `file_id`(string) · `kind`(version\|perm\|meta\|closed\|preview_ready) · `version_no`(int?) · `by`(uid) · `preview_url`(string? 仅 preview_ready) |
| doc.presence | `file_id` · `participants`[{uid,mode(edit\|comment\|view),ts}] · `event`(enter\|leave\|refresh) |
| doc.mention | `file_id` · `anchor`(string，评论锚点=DS 评论 id) · `from`(uid) · `snippet`(≤120 脱敏摘要) · `version_no` |
| doc.access.requested | `file_id` · `requester`{id,name} · `perm_requested`(viewer\|commenter\|editor) · `reason` · `req_id` |

示例（doc.updated kind=version）：

```json
{ "v": 1, "id": "s-88810", "type": "doc.updated", "ts": 1762420800123,
  "payload": { "file_id": "90001", "kind": "version", "version_no": 15, "by": "2003" } }
```

客户端处理：kind=version/perm/meta→Query 精准失效（['doc','file',id] 与列表 key，D01 §12.2-4）；preview_ready→停轮询渲染 PDF；closed→编辑器若仍开提示"会话已关闭"；presence/mention→doc store 与通知中心。
