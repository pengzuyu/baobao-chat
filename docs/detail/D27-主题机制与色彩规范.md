## 0. 一句话原则

**所有颜色只来自一处**：`client/src/shared/ui/themeConstants.ts`。antd 组件经 `ConfigProvider theme` 取色；残余自研 CSS 经 `--bbw-*` 变量取色——两者由 `cssVarsFrom()` 同源注入，切主题即时全局联动。**任何文件里出现硬编码色值（#xxxxxx / rgba 字面量）即违规**（语义明确的 antd 预设 Tag 色、mark 默认高亮等白名单除外，见 §5）。

## 1. 机制（两层一源 · 双维矩阵）

```
themeConstants.ts（唯一色源 = mode 基线 LIGHT/DARK × ACCENTS 主题色注册表）
 ├─ antdThemeFrom(mode, accent) ──→ providers.tsx <ConfigProvider theme>  ──→ antd 组件
 └─ cssVarsFrom(mode, accent)   ──→ providers.tsx useEffect 注入 :root     ──→ 残余自研 CSS var(--bbw-*)
```

- **mode 三态**：light / dark / system（`shared/store/theme.ts`），resolved 驱动 `<html data-theme>` + ConfigProvider + 变量注入。**默认 light**（2026-11-16 修订，11-14 曾拍 dark）；用户显式选择持久化于 localStorage(`bbw-theme`)。
- **accent 主题色**（修订2）：六套预置（见 §2.1），与 mode 正交组合；**只主色系（primary/hover/light 三档）跟随**，灰阶/语义色/表面分层不动。持久化 localStorage(`bbw-accent`)，默认 blue；无需 html 属性/防闪烁——providers 首帧内容前经 ConfigProvider + 变量注入生效。
- **Menu 选中态显式覆写**（修订2）：antd 默认 `itemSelectedBg=colorPrimaryBg`（主色调色板派生第 1 档），纯黑/近白主色派生异常（炭灰黑块），故 `antdThemeFrom` 内 components.Menu 以 accent 注册表三档显式覆写（`itemSelectedBg=t.light / itemSelectedColor=t.primary`），主导航竖排与设置/管理页水平菜单全局生效。
- **防闪烁**：`index.html` 内联脚本在 React 前按同规则设 `data-theme`；`tokens.css` 只作首屏兜底基线（主色=默认晨蓝，与 themeConstants 一致，React 挂载后由运行时注入接管）。
- **改色只改 themeConstants**：mode 基线（LIGHT/DARK）+ ACCENTS 注册表 + 两个工厂函数。tokens.css 跟随同步（仅兜底）。

## 2. 色板（亮=中性灰阶 · 暗=蓝调分层黑；主色系=六套 accent 可切换）

## 3. 开发守则（怎么写才合规）

1. **组件取色**：优先用 antd 组件默认（不传色）；需定制时 `const { token } = theme.useToken()` → `token.colorPrimary / colorBgContainer / colorTextSecondary / colorBorder…`（内联 style 或 antd props）。
2. **残余自研 CSS / 内联需与主题联动的色**：只用 `var(--bbw-primary)` 等 CSS 变量——它们已被注入为 antd 同源值。
3. **禁止**：`#2e6be6`（旧蓝，已退役）、`rgba(0,0,0,.x)` 等字面色值、以及从别的组件抄色值。WAAPI 等拿不到 token 的场景：读 `token.colorPrimary` 拼字符串（参考 ContactsPage 闪烁高亮）。
4. **语义优先**：状态用 success/warning/danger/error 表达；不要用主色代替语义色；主色（随 accent，默认晨蓝）仅用于品牌动作（主按钮/链接/选中），不要当背景大面积铺。
5. **主色系只从 ACCENTS 注册表取**（修订2）：组件不得自行派生主色 hover/浅底（antd 派生档对极端主色不可控）——需浅底用 `--bbw-primary-light`，需 hover 用 `--bbw-primary-hover`，其余交 antd 组件默认；新增/调整主题色=改 ACCENTS 注册表一行（亮/暗两档一起给），勿散落硬编码。
6. **新增颜色的流程**：先问「是否语义已有」→ 主色系进 ACCENTS 注册表、其余加进 themeConstants LIGHT/DARK 两套 + cssVarsFrom 映射 + tokens.css 兜底 + 本文档 §2 登记，缺一不可。
7. **新页面**：全 antd 组件 + 内联布局（Flex/Space/gap），不写 BEM 类不进 global.css（D26 口径）。
8. **白名单**（允许非 token 色）：antd Tag 预设色名（`color="purple"` 等）、`<mark>` 浏览器默认高亮、头像哈希取色算法内部、lucide 图标 currentColor、AccentSwatches 对勾前景 luma 推导。

## 4. 验收清单（改主题/加页面后自查）

- [ ] 亮/暗切换：antd 组件与自研 CSS（气泡/引用条/markdown 边框）同步变色，无残留旧色
- [ ] accent 轮换：六套 × 亮/暗，主按钮/链接/聊天气泡/引用条/菜单选中态联动；灰阶与红绿黄语义色不变
- [ ] 亮色菜单选中态=浅主色底+主色字（墨黑=浅灰底），无炭灰黑块
- [ ] 主题色双入口一致：设置页色板行=头像下拉快切，localStorage `bbw-accent` 重启保持
- [ ] 暗色分层可见：布局底 #0b0e14 上卡片 #11151d 有明确层次，边框可辨（蓝调非纯黑）
- [ ] `grep -rEn "#[0-9a-fA-F]{3,8}" client/src --include="*.tsx"`：除 themeConstants/AccentSwatches/白名单外零命中
- [ ] 主色只出现在品牌动作位；正文/次要文字走 gray-8/gray-6
- [ ] 首屏无闪色（默认亮色下 index.html 已设 data-theme=light；暗色用户同理）
