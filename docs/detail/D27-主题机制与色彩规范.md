> 状态：2026-11-14 定稿（用户拍板：①主题色黑 ②配色去「毛坯感」精修 ③全部颜色必须经 UI 组件库的主题机制全局配置）。

## 0. 一句话原则

**所有颜色只来自一处**：`client/src/shared/ui/themeConstants.ts`。antd 组件经 `ConfigProvider theme` 取色；残余自研 CSS 经 `--bbw-*` 变量取色——两者由 `cssVarsFrom()` 同源注入，切主题即时全局联动。**任何文件里出现硬编码色值（#xxxxxx / rgba 字面量）即违规**（语义明确的 antd 预设 Tag 色、mark 默认高亮等白名单除外，见 §5）。

## 1. 机制（两层一源）

```
themeConstants.ts（唯一色源）
 ├─ antdThemeFrom(mode) ──→ providers.tsx <ConfigProvider theme>  ──→ antd 组件
 └─ cssVarsFrom(mode)   ──→ providers.tsx useEffect 注入 :root     ──→ 残余自研 CSS var(--bbw-*)
```

- **mode 三态**：light / dark / system（`shared/store/theme.ts`），resolved 驱动 `<html data-theme>` + ConfigProvider + 变量注入。**默认 light**（2026-11-16 修订，11-14 曾拍 dark）；用户显式选择持久化于 localStorage(`bbw-theme`)。
- **防闪烁**：`index.html` 内联脚本在 React 前按同规则设 `data-theme`；`tokens.css` 只作首屏兜底基线（值与 themeConstants 一致，React 挂载后由运行时注入接管）。
- **改色只改 themeConstants**：LIGHT/DARK 两组常量 + 两个工厂函数。tokens.css 跟随同步（仅兜底）。

| 令牌 | 亮色 | 暗色 |
|---|---|---|
| success | `#16a34a` | `#4ade80` |
| warning | `#d97706` | `#fbbf24` |

### 2.5 基础常量（不变）

radius 6（控件）/卡片 10/气泡 12；字号 12/13/14/16/20；controlHeight 32；4px 间距栅格——见 tokens.css 对应段（这些不随主题切换，属静态令牌）。

## 3. 开发守则（怎么写才合规）

1. **组件取色**：优先用 antd 组件默认（不传色）；需定制时 `const { token } = theme.useToken()` → `token.colorPrimary / colorBgContainer / colorTextSecondary / colorBorder…`（内联 style 或 antd props）。
2. **残余自研 CSS / 内联需与主题联动的色**：只用 `var(--bbw-primary)` 等 CSS 变量——它们已被注入为 antd 同源值。
3. **禁止**：`#2e6be6`（旧蓝，已退役）、`rgba(0,0,0,.x)` 等字面色值、以及从别的组件抄色值。WAAPI 等拿不到 token 的场景：读 `token.colorPrimary` 拼字符串（参考 ContactsPage 闪烁高亮）。
4. **语义优先**：状态用 success/warning/danger/error 表达；不要用主色代替语义色；亮色「主色=纯黑反色」/暗色「主色=柔蓝」仅用于品牌动作（主按钮/链接/选中），不要拿白/黑/蓝当背景大面积铺。
5. **新增颜色的流程**：先问「是否语义已有」→ 没有则加进 themeConstants LIGHT/DARK 两套 + cssVarsFrom 映射 + tokens.css 兜底 + 本文档 §2 登记，四步缺一不可。
6. **新页面**：全 antd 组件 + 内联布局（Flex/Space/gap），不写 BEM 类不进 global.css（D26 口径）。
7. **白名单**（允许非 token 色）：antd Tag 预设色名（`color="purple"` 等）、`<mark>` 浏览器默认高亮、头像哈希取色算法内部、lucide 图标 currentColor。

## 4. 验收清单（改主题/加页面后自查）

- [ ] 亮/暗切换：antd 组件与自研 CSS（气泡/引用条/markdown 边框）同步变色，无残留旧色
- [ ] 暗色分层可见：布局底 #0b0e14 上卡片 #11151d 有明确层次，边框可辨（蓝调非纯黑）
- [ ] `grep -rEn "#[0-9a-fA-F]{3,8}" client/src --include="*.tsx"`：除 themeConstants/白名单外零命中
- [ ] 主色只出现在品牌动作位；正文/次要文字走 gray-8/gray-6
- [ ] 首屏无闪色（默认亮色下 index.html 已设 data-theme=light；暗色用户同理）
