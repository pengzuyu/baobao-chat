## 1. 目的与范围

定义客户端的：窗口体系、全局导航与路由、布局系统与**响应式断点**、设计令牌、**六态数据响应规范**、反馈体系、快捷键、拖拽/粘贴规范、前端工程模块划分、本地能力接口层。各功能模块的页面/交互/接口/模型细节见对应模块篇（D03~D11），模块篇必须遵守本文约定。

**"响应设计"在本系列包含三层含义**（各模块篇都要覆盖）：
1. **窗口响应式**：不同窗口宽度档位下的布局变化（§5 断点体系 + 各篇响应式适配表）；
2. **数据状态响应**：每个数据视图的六态（loading/empty/error/offline/forbidden/degraded，§7）；
3. **性能响应**：乐观更新、流式渲染、骨架屏等即时反馈（§7.7）。

## 5. 布局系统与响应式断点

### 5.1 主窗三栏模型

```
┌──┬────────────┬──────────────────────────────┬──────────────┐
│导│ 二级列表栏   │  内容区                        │  详情侧栏      │
│航│ (会话列表/   │  (消息流/文档/检索结果/          │ (群信息/文档   │
│栏│ 文档树/会话  │   Agent 工作台等)               │  信息/任务详情) │
│56│ 列表等)     │                              │              │
│px│ 264px      │  flex:1                      │  304px       │
│  │ 可折叠→56px │                              │  可折叠       │
└──┴────────────┴──────────────────────────────┴──────────────┘
```

### 5.2 断点四档（以主窗内容区宽度计）

| 档位 | 宽度 | 布局行为 |
|---|---|---|
| **XL** | ≥1600 | 三栏全展开；内容区可容纳双面板（如消息流+引用预览） |
| **L** | 1280–1599 | 三栏可用；详情侧栏默认浮层化（从右侧滑出、遮罩），可固定 |
| **M** | 1024–1279 | 二级列表栏默认收窄为 56px 图标条（悬停展开抽屉）；详情侧栏强制浮层 |
| **S** | 720–1023 | 单栏模式：列表⇄内容两级导航（点击列表项进入内容区，左上返回）；导航栏保留 |

通用规则：断点切换**不丢状态**（滚动位置/草稿/选中项存 feature store）；用户手动折叠偏好持久化并优先于默认档位行为；最小窗口 960×600 对应 S 档上限附近，必须可用。

### 5.3 各模块的栏占用

| 模块 | 二级列表栏 | 内容区 | 详情侧栏 |
|---|---|---|---|
| IM | 会话列表 | 消息流 | 群/会话信息 |
| 通话 | 最近通话 | 历史详情 | —（通话本体在独立窗） |
| 文档 | 我/共享/部门/公司 树 | 列表 或 编辑器 | 文档信息/版本 |
| 知识库 | 空间/目录树 | 内容/检索 | 文档信息 |
| Agent | 会话列表 | 工作台三区 | 审批队列/检查点（L 档起） |
| 管理 | 模块树 | 管理页 | — |

## 7. 六态数据响应规范（每个数据视图强制，模块篇逐页登记）

| 态 | 触发 | 视觉 | 允许的操作 |
|---|---|---|---|
| **loading** | 首次拉取 | 骨架屏（列表=条形骨架×8；详情=块骨架；流式区域=shimmer 行） | 不可操作；>300ms 才显示（防闪烁） |
| **empty** | 空数据 | 插画+一行说明+主 CTA（文案各模块篇定义） | CTA |
| **error** | 请求失败 | 图标+错误文案（按错误码映射）+"重试"；`trace_id` 折叠可复制 | 重试/反馈 |
| **offline** | WSS 断开 | 全局顶部横幅"连接中…/已离线"，内容区显示本地缓存+半透明遮罩提示 | 浏览缓存、编辑草稿、重发队列（04 篇 outbox） |
| **forbidden** | 2003/2001 等 | 锁图标+无权限说明+「申请权限」入口（doc/kb 场景） | 申请/返回 |
| **degraded** | 依赖降级（02 篇 §7） | 顶部黄条告知降级模式（如"编辑暂不可用，已切换只读预览"） | 只读操作/下载 |

### 7.7 性能响应规范

| 场景 | 规范 |
|---|---|
| 发消息 | **乐观更新**：本地立即上屏 `state=sending`（灰钩），ack 后 `sent`（单钩），失败 `failed`（红叹号+重试菜单） |
| 流式渲染（Agent 输出/输入中状态） | 50ms 批量 flush；代码块增量高亮；自动吸底（用户上滚则停随，显示"回到底部"浮标） |
| 长列表 | 虚拟滚动（react-virtuoso），消息 key=`{convId}:{seq}`；跳转锚点定位（点击未读→定位第一条未读 seq） |
| 图片 | 先缩略图（240 webp）→点击加载 720 →查看器内原图；聊天流内懒加载 |
| 二级列表 | TanStack Query 缓存 + 预取下一页；列表变更走 WS 推送的精准失效 |

## 8. 反馈体系

| 反馈 | 规范 |
|---|---|
| toast | 右上角；success 3s / info 4s / error 6s（含"查看详情"）；最多堆叠 3 条 |
| 表单校验 | 内联红字+字段描红，提交时定位首个错误；错误码 9001 映射字段级文案 |
| 确认弹窗三级 | 普通（取消/确认）；**危险**（红色确认钮，如解散群/彻底删除）；**高危**（需输入确认词或口令，如租户销毁、平台 killswitch，12 篇矩阵） |
| 进度 | 确定性=进度条（上传/下载/导入）；非确定性=spinner（仅 <1s 的未知等待，超过 1s 改为骨架/进度） |
| 通知中心 | 聚合 @我/回复/审批/Agent 完成/系统公告；与系统通知（托盘）联动；勿扰时段只入中心 |
| 红点 | 数字（99+封顶）/ 红点 / @红标 三级；规则：@我>提及>普通（04 篇） |
| 声音 | 来电铃声/新消息（默认关）/通话进出；全局可关 |

## 12. 前端工程模块划分 ★

### 12.1 目录结构（到二级）

```
src/
├─ app/                  # 应用壳：路由、全局布局、Provider、全局事件绑定
├─ features/             # 业务模块（互相隔离）
│  ├─ auth/  im/  rtc/  doc/  files/  kb/  agent/  eco/  admin/  settings/
│  └─ <feature>/         # 统一内部结构：
│      ├─ pages/         #   页面（对应 Pxx-xx）
│      ├─ components/    #   模块内组件
│      ├─ api/           #   该模块 REST/WS 事件封装 + Query hooks
│      ├─ store/         #   模块 UI 态（Zustand）
│      ├─ model/         #   TS 类型（与服务端 schema 同源生成）
│      └─ events.ts      #   对外广播/订阅的模块事件
├─ shared/
│  ├─ api/               # http 客户端、ws 客户端、Query key 工厂、错误码→文案表
│  ├─ ui/                # 设计基元（Button/Input/Avatar/Badge/Skeleton/Empty/DiffView…）
│  ├─ components/        # 跨模块业务组件（FileCard/UserPicker/PermissionDrawer/Present）
│  ├─ bus/               # 模块间事件总线（见 12.2）
│  ├─ store/             # 全局态（会话/连接状态/主题/在线状态）
│  └─ utils/ types/ i18n/
└─ styles/               # tokens.css（§6）
```

### 12.2 依赖规则（CI 用 eslint-boundaries 强制）

1. `features/*` **禁止横向 import** 其他 feature；跨模块通信只用两条路：`shared/bus`（如 im 内嵌 agent 卡片、doc 权限变更通知 kb）或提升到 `app/` 组合层。
2. `shared/**` 禁止 import `features/**`。
3. `shared/ui` 保持哑组件（无业务、无请求）。
4. TanStack Query key 工厂集中在 `shared/api/keys.ts`：`['im','convs',params]`、`['doc','file',id]`；WS 推送精准失效映射表集中维护。
5. 状态归属：**服务端态→Query 缓存**；**模块 UI 态→feature store**；**全局态（连接/在线/主题/当前用户）→shared/store**；**持久化（草稿/折叠/游标）→Rust SQLite**（经 IPC，禁止 localStorage 存业务数据——多端漫游走 user_conv_state）。

### 12.3 本地能力接口层（UI→Rust 命令，命名 `模块_动作`）

| 分组 | 命令（示例） | 说明 |
|---|---|---|
| 窗口 | win_minimize / win_toggle_pip / win_set_badge | |
| 文件 | fs_pick_dir / fs_open_path / fs_save_as | 系统 UI 由 Rust 弹出 |
| 传输 | transfer_start / transfer_pause / transfer_cancel / transfer_retry | 进度经事件回推 |
| Agent | agent_start_session / agent_stop / agent_input / agent_set_mode | 会话与流式经事件回推（08 篇协议） |
| 凭据 | cred_lock_screen / cred_logout | |
| 系统 | sys_set_autostart / sys_open_url | 外链走系统浏览器 |

命令均为 `invoke()` 白名单注册（Tauri ACL），页面沙箱外不可见（02 篇 §2 要点 2）。
