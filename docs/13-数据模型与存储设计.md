## 1. 公共规范（所有表强制）

| 项 | 约定 |
|---|---|
| 主键 | 雪花 ID（趋势递增），对外字符串透出；会话内消息另有单调 `seq`（04 篇） |
| 租户隔离 | 所有业务表含 `tenant_id`；PG RLS 按 `current_setting('app.tenant')` 过滤（03 篇 §3.2）；高合规租户可选独立库/独立 schema |
| 时间 | 一律 UTC 存储（timestamptz），展示端本地化；排序以服务端时间为准 |
| 软删除 | `deleted_at` 可空列（文档/文件/知识库用）；知识库删除为 GDPR 式物理清除（11 篇） |
| 审计 | 高价值表变更由 audit 域事件表统一留痕（15 篇哈希链），不在业务表上做触发器 |
| 扩展 | 预留 `extra jsonb`；禁止裸 `ALTER` 破坏兼容，字段演进走 14 篇 §8 兼容窗口 |
| 命名 | 表名小写下划线；域前缀分组（`im` 隐含在 conversation/message、`doc_`、`kb_`、`eco_`、`admin_`、`agent_`） |

## 2. ER 总览（域级）

```
tenant ─┬─ dept ── user ─┬─ user_role ── role
        │                ├─ device ── refresh_token
        │                └─ (各域 user_id 外键)
        ├─ conversation ─ conversation_member ─┐
        │        └── message(分区) ────────────┤ 统一 resource_acl(03)
        ├─ file_blob ── file ── file_share_link │ (resource_type × resource_id)
        ├─ doc_file ─ doc_version/doc_session…  │
        ├─ kb_space ─ kb_node ─ kb_doc_meta ── kb_chunk(向量)
        ├─ eco_app ─ eco_app_version/connector/rollout · skill_package(+version) ─ user_app_state
        ├─ admin_policy/admin_task/admin_approval/admin_operation · tenant_quota
        └─ audit_event(哈希链) · audit_anchor · security_key · feature_flag

客户端本地（SQLite）: local_message(+FTS5)/local_conv/outbox · agent_*
```

## 8. 容量估算基线（单租户 2 万用户、60% 日活）

| 表/对象 | 日增 | 年增 | 备注 |
|---|---|---|---|
| message | ~1,200 万行/日（人均 1k 条） | ~44 亿行 → 按月分区 + 90 天热数据在线，冷分区转储备份 | 分区交换归档 |
| message_receipt | 日增≈活跃会话×成员数（聚合行更新为主） | 行数远小于消息 | 游标聚合的红利 |
| file_blob | 按去重后物理量（经验值≈逻辑量 70%） | — | 容量按租户配额控制 |
| kb_chunk | 文档数 ×（页数/2）量级 | 千万级内 pgvector HNSW 无压力 | 超 5 千万再评估 Milvus |
| audit_event | 消息/文档/Agent/OBO 动作采样+全量管理操作 | 年亿级 → 分区 + 锚点独立库 | 追加写为主 |

## 9. 索引与约束要点（DBA 检查清单）

1. message：UK(conv_id, seq)、UK(client_msg_id)、(tenant_id, created_at) 分区裁剪索引；分区按月，新建分区预建未来 3 个月。
2. kb_chunk：HNSW(embedding vector_cosine_ops) + GIN(fts) + GIN(acl_tags jsonb_path_ops)；嵌入写入走摄入队列，禁止同步事务内嵌入。
3. file_blob：UK(tenant_id, sha256)；ref_count 增减与 file 删除同事务；引用归零进入 GC 候选（延迟 7 天防竞态）。
4. resource_acl：(resource_type, resource_id) 覆盖索引 + (grant_target) 反查"某人授予了什么"（离职交接用，12 篇）。
5. audit_event：只 INSERT；每月分区；prev_hash→hash 链校验为定时任务（断裂即 P1 告警，15 篇）。
6. 所有业务表 RLS 策略与单元测试强制（15 篇：RLS 测试基类 CI 阻塞合并）。

## 10. 演进与触发条件

| 触发 | 动作 |
|---|---|
| 消息检索 P95 > 1.5s 或活跃消息 > 5,000 万 | 全文检索外移 OpenSearch（01 篇预案） |
| kb_chunk > 5,000 万 | 向量外移 Milvus（双写迁移窗口） |
| 单租户 PG 主库写入 > 60% 持续 | 拆分 message 域为独立库（模块化单体的拆分预案，02 篇） |
| 高合规租户 | 独立库/桶 + 独立 KMS 密钥域 |

## 11. 依赖与开放问题
